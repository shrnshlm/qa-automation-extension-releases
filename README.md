# QA Automation Extension — Public Releases

Download the latest extension zip from the **Releases** page on the right.

## Install on Chrome (Windows or Mac)

1. Download `qa-automation-extension-vX.Y.Z.zip` from the latest release.
2. Unzip it to a permanent folder (e.g. `C:\qa-extension\` on Windows).
3. Open `chrome://extensions` in Chrome.
4. Turn on **Developer mode** (top-right toggle).
5. Click **Load unpacked** and pick the unzipped folder.
6. The extension icon appears in the toolbar.

For full functionality (mobile testing), also install
[ScenarioReplay](https://github.com/shrnshlm/ScenarioReplay).
